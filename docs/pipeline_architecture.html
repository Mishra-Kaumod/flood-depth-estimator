Stage 1 — Water Detection & Validation SegFormerHSV+CV2
Find water pixels. Reject false positives (dry roads, soil, texture artefacts).
RGB Image (PIL) → water_mask · water_pct · water_confidence (0–1) · flags[]

SegFormerYoloDepthV2Pipeline
_segformer_water_mask(image_rgb)
Loads nvidia/segformer-b2-finetuned (HuggingFace). Semantic segmentation → coarse water mask. Hands off to WaterRegionDetector for HSV refinement + validation.
CORE
src/water_region_detector.py
WaterRegionDetector
detect_validated(image_rgb) → (mask, pct, conf, flags)
HSV range detection. 5 false-positive checks: A) Texture (Laplacian variance), B) Pixel scrub, C) Connectivity, D) Height prior (top 30% zeroed), E) Colour diversity. Returns confidence 0–1.
CORE
src/segformer_yolo_depthv2_pipeline.py
SegFormerYoloDepthV2Pipeline
_segformer_scene_comment(mask, pct, depth, conf, flags)
Fallback when no scale anchor. Generates plain-English scene description: water %, top/bottom distribution, depth cue. Returns (str, dict) for UI amber card.
FALLBACK

Stage 2 — Reference Object Detection (Scale Anchor) YOLOv8n
Detect cars / persons / bikes / trucks. Measure how submerged they are to get a real-world depth anchor.
RGB Image + water_mask → reference_depth_cm (float | None) · detected_objects[] · submersion_ratio
yolov8n.pt
YOLOv8n Weights (6.3 MB)
ultralytics.YOLO("yolov8n.pt").predict(img)
COCO-80 classes. Reference objects: car (h≈1.5m), person (h≈1.75m), bus (h≈3.5m), truck (h≈2.5m), motorcycle (h≈1.1m), bicycle (h≈1.0m). Auto-downloads if missing.
WEIGHT
src/reference_depth_estimator.py
ReferenceDepthEstimator
estimate(image_np, water_mask) → (depth_cm, objects[])
Clips each bbox against water mask. Computes submersion_ratio = submerged_px / bbox_height. Multiplies by known object height → depth_cm. Returns best anchor.

Stage 3 — Dense Depth Map (DepthAnythingV2) Transformer
Per-pixel monocular depth estimation (0–1 proxy). Works even without reference objects.
RGB Image → dense_depth_map (np.array H×W, 0–1)
src/segformer_yolo_depthv2_pipeline.py
SegFormerYoloDepthV2Pipeline
_depthanything_map(image_rgb) → depth_np
Loads depth-anything/Depth-Anything-V2-Small-hf via HuggingFace. AutoModelForDepthEstimation. Returns normalised depth map resized to original image dimensions.
CORE
↓
4
Stage 4 — Fusion Engine Weighted Blend
Fuse reference anchor + dense depth + water coverage into a single depth estimate. Suppress if water is unreliable.
ref_depth_cm + dense_depth_map + water_pct + water_confidence → fused_depth_cm (float | None) · confidence (0–1)
src/segformer_yolo_depthv2_pipeline.py
_fuse_depth_estimates(ref, dense, pct)
With anchor: depth = 0.65×ref + 0.35×dense
No anchor: depth = dense only (cap conf 0.55)
water_confidence < 0.45 → depth = None (SUPPRESSED)
Decision: if water signal is unreliable (dry road, high texture), depth is withheld entirely. UI shows red DEPTH WITHHELD badge instead of a number.
CORE
↓
5
Stage 5 — Calibration, Severity & Response EfficientNet-B3 Gemini (optional)
Map fused depth → severity bucket. Optionally blend Gemini API result. Return JSON to browser.
fused_depth_cm + image tensor → severity · confidence · full JSON response
src/segformer_yolo_depthv2_pipeline.py
_calibration_severity_model(depth_cm, pct, conf)
Buckets: <15cm→SAFE · 15–45cm→MODERATE
45–90cm→SEVERE · >90cm→CRITICAL
Loads EfficientNet-B3 water-aware checkpoint for final classification cross-check. Returns severity label + confidence score.
CORE
